Notebook, as the mod draws it

These are the trees progress-pane 0.3 returns to the engine, captured from its test harness for a sample run with five subagents (one owl, one songbird, two frogs, one fox; one finished, one failed) and rendered here. Terminal panels emulate a dark terminal in a monospace grid, with companions decoded from the real Raster cells. Desktop panels use a proportional font, as the app does, with the real SVG companions. Colors approximate a dark theme; times read "2m" because the harness clock starts at zero.
